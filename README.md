# Excel Assignments and Practice

## About This Repository

This repository contains my Excel learning exercises and assignments completed as part of my journey towards becoming a Data Analyst.

The main objective of these assignments is to develop practical knowledge of Microsoft Excel, understand data manipulation, perform data cleaning, and apply Excel formulas to solve real-world data problems.

## Topics Covered

### 1. Excel Basics
- Working with rows, columns, and cells
- Entering and organizing data
- Basic data operations
- Formatting and managing datasets

### 2. Excel Functions and Formulas
- SUM()
- AVERAGE()
- COUNT()
- COUNTA()
- AutoSum

### 3. Data Cleaning
- TRIM() – Removing unwanted spaces
- PROPER() – Converting text into proper case
- LOWER() – Converting text into lowercase
- Handling inconsistent names and email formats
- Identifying duplicate records

### 4. Lookup Functions
- VLOOKUP()
- Retrieving product prices using Product IDs
- Matching records between datasets

### 5. Text Manipulation
- LEFT()
- RIGHT()
- MID()
- Extracting specific characters from text
- Working with city codes, months, and years

## Assignments Included

| Assignment | Description |
|---|---|
| Day 6 | Sales data analysis using SUM, AVERAGE, COUNT and COUNTA |
| Day 7 | Customer data cleaning using PROPER, TRIM and LOWER |
| Day 8 | String manipulation using LEFT, RIGHT and MID |
| Day 9 | COUNT function practice |
| Additional Practice | Basic Excel operations, lookup functions and customer/sales data handling |

## Learning Outcomes

Through these assignments, I practiced:

- Cleaning raw datasets and standardizing inconsistent text.
- Identifying and handling duplicate customer records.
- Calculating total and average sales.
- Counting numeric and non-empty values.
